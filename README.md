# blum

архивный эксперимент 2024 года: два userscript для автоматизации мини-игры Blum в Telegram.

- `blumforbrowser.user.js` — версия для браузерного userscript-менеджера;
- `blumforzennoposter.user.js` — расширенная версия с дополнительной автоматизацией.

репозиторий сохранён как история эксперимента и не поддерживается. совместимость с текущим Blum и Telegram не проверяется.

второй файл содержит обфусцированный сторонний код, удалённую проверку обновлений и загрузку данных из внешнего репозитория. перед любым запуском изучите исходники и решите, доверяете ли этим зависимостям.
